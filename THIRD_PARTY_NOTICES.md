# Third-party / interoperability notes

NHRA Tech Data includes an independent MoTeC LD reader based on publicly documented/reverse-engineered format knowledge. MIT-licensed projects were consulted as interoperability references during development, including the `i3rs` MoTeC LD parser/viewer.

The application does not bundle MoTeC software or proprietary MoTeC source code.

The drag-racing forward/reference model was developed from legacy Quarter Pro source material supplied for this engineering project. That source is used as a historical physics/reference implementation; it is not the product identity of NHRA Tech Data.
